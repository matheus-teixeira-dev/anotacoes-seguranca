# Comandos básicos do Linux

- `ls`: mostra os arquivos e pastas do diretorio que você está atualmente
- `history`: verifica o histórico de comandos usados pelo usuario pode ser complementado com o "| grep" para pegar um comando especifico
- `pwd`: mostra o caminho completo até o diretório atual
- `cd`: entra em um diretório , usando cd .. volta um diretório
- `cat`: verifica o conteudo do arquivo
